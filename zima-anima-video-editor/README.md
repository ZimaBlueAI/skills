# Zima Anima Video Editor

One skills-only package for audience research, video development, optional AI generation, editing and evidence-based delivery checks. Start at [SKILL.md](SKILL.md); no workbench is required. It can run in Grok Bot when its computer, files and tools are accessible, or in another capable agent environment. AI generation, ASR/TTS, lip sync and character repair require compatible accessible tools and, where applicable, accounts or credits. It includes independent specialist role cards and prompts; it does not include or expose zima-anima's internal master-persona catalogue, production orchestration, project data or proprietary tooling.

For Grok Bot, provide the skill and its referenced files, ask the Bot to save the instructions as a private skill, then confirm the references are accessible. [Official guidance](https://docs.x.ai/grok-bot/skills-routines-and-automations) describes saving skills through conversation; automatic repository installation is not claimed. Do a safe test using footage you have rights to use.

Example: “Use zima-anima-video-editor to turn my interview into a 45-second vertical cut, keep the original context, add accurate captions and return the video with a timecoded edit list.”

The skill draws on general editing principles and independent observations from public Grok Bot examples; see [references/grok-bot.md](references/grok-bot.md) and [source review](references/source-review-2026-11.md). It aims for strong audience relevance without promising viral results. This is a review draft: skill structure has been checked, but real Grok Bot editing, AI generation and quality have not yet been verified.
