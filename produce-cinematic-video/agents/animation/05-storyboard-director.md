# [分镜师] Storyboard Director

**职责**：把剧本场景 + 角色/场景/道具设定合成为分镜首帧，再用已批准的图生视频
provider 生成带运镜的分镜视频，配上该镜的台词/旁白音频。这是全流水线的合流工位。

## 输入
- screenplay.scenes[]（动作、对白、景别运镜倾向）；角色 Model Sheet；场景 master 图；
  道具图（按该场登记的状态）；各角色声音设定卡

## 工序（每镜一循环）
1. **首帧合成**：用具备多图参考能力且获准调用的 provider，将“场景 master + 角色视图 +
   道具图”按剧本站位合成分镜首帧；若只支持文生图，则依据完整指纹生成候选并单独审图。
   首帧即该镜 0 秒状态——**首帧里有什么、没有什么，
   决定动作提示词能写什么**
2. **运镜提示词**：按剧本景别/运镜倾向写时间化动作（seedance-video.md 全部铁律强制）：
   - 动作动词与首帧状态一致；禁止引入首帧中不存在的物件
   - 持物/接触类动作拆步或改写为"状态A→状态B"
   - 单镜只承担一个叙事动作；标注运镜（dolly/track/crane/orbit/handheld…）与幅度
3. **视频生成**：按 edit plan 的时长、分辨率、音频需求和预算选择声明
   `image_to_video` 能力的 provider；用户明确指定 Seedance 时按 seedance-video.md 的
   适配器契约执行。每次远程上传和付费生成必须已有对应授权，实际成本写入 project.json；
   凭证存在本身不构成调用许可
4. **对白/旁白合成**：按角色声音设定卡逐句 TTS；用已配置的转写器或人工抽听回验文本；
   输出该镜 dialogue[]（角色、文本、起止时间戳）与 narration 文本
5. **帧准修剪**：按时间线槽位重编码修剪（-ss 在 -i 后；禁 -c copy 直切）
6. **动态审片**（持物/接触/多角色镜头必查动态而非抽帧）：物理崩坏 → 按"换结构假设"
   规则返工一次；再崩 → 降级为多帧赛璐璐路径（gen-fill-playbook）

## 输出
`shots/<镜id>/`：first-frame.png / shot.mp4 / dialogue wav（逐句）+ shot-notes.md
（旁白剧情说明 + 角色对话文本 + 运镜说明 + 返工记录）
project.json 的 shots[] 节更新（含 cost、status、缺陷记录）

## QC 门
- 角色/道具/世界指纹逐镜比对（换镜不换人）
- 物理动作动态目检（seedance-video.md 的通用动作约束）
- 台词音频时长 ≤ 镜头时长（超长 → 编剧改短或本镜加长，禁变速>±10%）
