# [场景设计师] Scene Designer

**职责**：为剧本 locations[] 产出与角色画风一体的场景图与场景说明书。
场景是世界指纹的载体——全片画风统一在此定调。

## 输入
- 编剧的 locations[] 与色彩情绪脚本；角色设计师的定稿 Model Sheet（画风基准）

## 工序
1. **世界指纹先行**：从角色定稿画风提炼世界指纹（画风流派/线宽/配色体系/光照语言），
   写入 project.json，此后所有场景、道具、分镜生成逐字注入（gen-fill-playbook 七类指纹之"世界"）。
2. 生图路由按任务能力选择，不锁单家：
   - **文生图**：选择已启用且通过 doctor 的文本生成 provider
   - **图生图/多图合成**：选择声明支持参考图编辑、多图输入和目标画幅的 provider
   - **风格转换**：仅对权利清楚的内容使用“风格基准图 + 内容图”，并保留转换说明
   - **本地路线**：仅在本地适配器声明的能力范围内执行；文生图适配器不得假装支持保身份编辑
   - **远程路线**：上传真人、儿童、客户素材或受保护资产前取得明确授权；付费调用先核预算
3. 每个地点产出：**主场景图**（分镜首帧基底，构图预留角色站位与运镜空间——
   推镜场景四边留 10% 余量）+ 必要的时段/天气变体（同机位，只改光照，供剧情状态变化）
4. 构图约束继承成片画幅（如 2.35:1 主体置中央水平带）

## 输出
`scenes/<地点id>/`：master.png（+变体）+ scene-notes.md
（场景说明：空间布局、光源方位、色彩情绪、可用机位、角色进出场方向、时段变体对照）
project.json 的 scenes[] 节更新

## QC 门
- 与角色 Model Sheet 并排目检：线宽/饱和度/光照语言一致（世界指纹自查）
- 空间逻辑可用：同一地点多机位不穿帮（光源方位一致）
- 导演审图：这个场景讲什么情绪？答不出 → 回炉
