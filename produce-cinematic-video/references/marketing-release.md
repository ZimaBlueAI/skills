## 建立营销命题

先填六项，不从“怎么剪得爆”开始：

1. **Audience：** 谁在什么场景、设备和注意力状态下观看？
2. **Problem/Desire：** 他正在解决什么或想获得什么？
3. **Promise：** 这支片明确承诺什么观看价值？
4. **Proof：** 哪些人物、行为、过程、产品、数据或结果支持承诺？
5. **Payoff：** 观众何时、如何得到兑现？
6. **Action：** 下一步行为是什么，为什么现在值得做？

把品牌目标转成观众可见的变化。避免只有“高级、年轻、治愈、科技感”的内部形容词。

## 把承诺变成证据

为每条营销主张记录：

- 原句与面向受众；
- 主张类型：事实、性能、比较、价格、稀缺、体验、意见或见证；
- 证据文件、来源、时间码和适用条件；
- 必要限定语和披露；
- 法务/品牌/客户批准状态；
- 在视频中的可读时长。

优先展示使用情境、可观察行为和真实结果。不要用合成画面、非典型结果、加速过程、模拟 UI 或戏剧化重演暗示未发生的产品表现。

## 设计主版与变体

先形成一个叙事与证据成立的 editorial master，再为渠道改变入口、长度、比例、字幕、包装和 CTA。若项目从一开始只为单一渠道制作，可以直接按该 viewing context 设计，但仍保留干净母版。

每个变体记录：

- version ID、平台、位置和受众；
- 画幅、安全区、字幕、音频默认状态和交付规格；
- opening device、首个价值信号、首次 payoff 和主要 payoff 时间；
- 删除、重排、替换或新增内容；
- title/thumbnail/cover/caption/CTA；
- 假设、成功指标和与主版的差异。

不要把横版机械中心裁成竖版。重新构图人物视线、字幕、产品、手部和动作方向；需要时使用独立镜头或图形版式。

## 研究平台和风格

平台规格、功能和分发机制会变化。每次正式发行前：

1. 优先读取平台官方上传、广告、字幕、合成内容和社区政策；
2. 记录来源 URL、访问日期、地区、账号类型和不确定项；
3. 用用户自己的账号数据校准，不把公开“算法秘籍”当事实；
4. 区分技术限制、内容政策、用户习惯和当前假设；
5. 只采集公开且允许研究的信息，遵守条款、版权、隐私和频率限制。

按 viewing context 思考，而不是背平台神话：

| 情境 | 剪辑重点 |
|---|---|
| 滑动信息流 | 首帧对象/价值可读、快速建立问题、静音可理解 |
| 搜索/教程 | 迅速确认问题匹配、过程完整、章节和可保存价值 |
| 社区/长视频 | 范围承诺、人格、论证、章节、互动节点 |
| 广告位 | 品牌/产品识别、主张证据、合规限定、明确行动 |
| 影院/展映 | 声画尺度、沉浸、节奏耐心、场地与校准 |

## 拆解可复现特征

风格学习只提炼模式，不搬运素材。

建立目的性样本：

- 目标品类与相近受众；
- 表现较好的样本；
- 同时期、同品类的普通或低表现对照；
- 日期范围、筛选条件、样本偏差和缺失信息。

不要因为播放高就断言某个剪辑特征导致成功。比较以下可观察特征：

- opening device、承诺出现时间、首次/主要 payoff；
- 结构段落、信息顺序、时长分布；
- ASL 中位数与分布、密度曲线、留白和节奏变化；
- 构图、景别、运动、色彩、文字和视觉证据；
- 对白比例、音乐结构、声效、静默和响度；
- 标题、封面、字幕、CTA、评论触发；
- 负面反馈、误解、跳出点和争议。

只把在目标组与对照组之间有稳定差异、且符合内容机制的特征写入 style card。附样本、证据、置信度、适用边界和失效条件。

## 执行发布前诊断

不要只给总分。按证据输出：

1. **Audience fit：** 目标观众和观看场景是否明确？
2. **Promise clarity：** 观众何时知道能得到什么？
3. **Proof strength：** 承诺是否被画面、声音或事实支持？
4. **Payoff：** 兑现是否及时、充分且与开场一致？
5. **Comprehension：** 静音、手机、小屏、字幕和快扫是否仍可理解？
6. **Emotional design：** 是否有变化、对比、呼吸和记忆点？
7. **Packaging：** 标题/封面/首帧是否准确而有区分度？
8. **Action fit：** CTA 是否自然、具体且不损害信任？
9. **Trust risk：** 是否有夸大、伪证据、未披露合成、版权或价值观风险？
10. **Technical readiness：** 规格、字幕、响度、安全区和播放是否通过？

每项给 observation、evidence、confidence、impact 和 recommended change。评分与预测的完整证据合同见 `references/evaluation-and-forecasting.md`；可用 `scripts/evaluate_video.py` 生成结构化报告。只有所有维度都有证据时才显示完整总分。

点赞率、完播率、点击率、线索率和客户转化率只能从同平台、同形式、相近主题且分母清楚的第一方历史数据建立经验区间。默认至少需要 30 条可比内容和足够分母；不足时必须输出 `not_estimable`。该区间是相关性基线，不是因果推断或结果承诺。

## 运行 AB 学习

每次只改变一个主要变量：

- 开场镜头或首句；
- 信息顺序；
- 标题/封面；
- 片长或首次 payoff；
- CTA；
- 字幕密度；
- 音乐/无音乐。

保持受众、投放、时段、预算和其他包装尽量一致。预先定义成功指标和观察窗口；避免看到数据后临时改指标。把版本差异写入 manifest，而不是凭文件名猜。

创意 A/B 不是为了证明“谁更爆”，而是降低某个具体不确定性。

## 回收真实数据

按内容和渠道选择：

- impressions/reach；
- 3 秒或首段留存；
- average watch time、completion、drop-off；
- save/share/comment 及其内容；
- profile/product click；
- lead、purchase、conversion 和退款；
- negative feedback、hide、unfollow；
- 定性访谈和可理解性测试。

保存发布时间、受众、流量来源、付费/自然、创意版本和样本量。比较率之前检查分母和流量质量。短期播放、长期品牌、转化和满意度不是同一目标。

小量自有数据可以做漏斗诊断，不能自动支撑预测模型。即使已有 20 条内容，仍需检查同质性、选择偏差、季节和投放差异。

## 保持诚实边界

- 不承诺播放、获赞、成交、爆款概率或绝对排名。
- 不把相关性写成因果。
- 不把平台传闻写成官方机制。
- 不用焦虑、对立、羞辱或伪稀缺换短期指标而隐瞒长期信任成本。
- 不保存或复用他人受保护素材来“复刻风格”。
- 不把法律风险清单当法律结论；高风险主张交给合格审查人。
- 所有建议注明证据、日期、适用范围、置信度和下一次可验证实验。
