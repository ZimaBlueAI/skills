# 生成补齐手册

四条修补路径。每个 gap 先过决策树，再调用任何生成服务。优先使用已有素材、
剪辑结构、静帧运镜或本地确定性处理；远程上传与费用授权是两个独立闸门。

## 成本规则

- 价格只从本次调用时的 provider 报价、账户回执或用户提供的费率读取，不把历史价格写成长期事实
- 预算只来自用户批准或项目 manifest；没有预算时保持 dry-run，不自行设默认额度
- “无法获得价格”不等于免费；先生成估算与请求参数，等用户确认
- `gap_list.json` 每项记录 `est_cost`、`actual_cost`、币种、计费依据与审批记录
- 能用静帧、局部编辑或已有素材解决时先比较质量、隐私与成本，再决定是否生成视频

## 参考图角色协议（所有生成路径通用）

给生成 provider 的每张参考图必须标注 role（写入 edit_plan 的
`source.references`），不许一把图乱塞；具体可组合的 role 以所选适配器契约为准：

| role | 用途 |
|---|---|
| first_frame / last_frame | 首尾帧模式专用（与多模态参考模式互斥） |
| reference_character | 角色一致性（多镜头同一人物/形象） |
| reference_prop | 道具一致性（产品、物件） |
| reference_composition | 构图参考 |
| reference_style | 风格/色调参考 |
| reference_stage | 场景/舞台参考 |
| reference_target_state | 目标状态（配 continuity.mode=strict，约束镜头结束时画面应到达的状态） |

**连续性控制**：多镜头连续生成时设 `continuity.chain_from_previous=true`——用上一镜**真实渲染尾帧**（不是生成时的预期尾帧）作为本镜 first_frame，硬保证镜头衔接；角色/场景一致性靠 reference_character/reference_stage 贯穿各镜，不靠提示词里"同一个人"这种软约束。

**连续性指纹（continuity fingerprint）**：跨帧/跨镜生成时，为每个需要保持一致的实体先写一段固定的锚点描述，**逐字**注入每一次生成的提示词，并存档到项目（如 `continuity-fingerprint.md`）供审计。指纹按七类建立，项目里出现哪类就建哪类：
- **人物**：脸型、发型发色、体态比例、标志性特征
- **服装**：款式、花纹、沿边色、磨损细节（换装景要为每套服装单独建指纹）
- **武器/道具**：形制、材质、纹章、佩戴位置
- **敌人/生物**：体型尺度（相对主角）、鳞甲/皮毛特征、发光部位
- **世界**：画风流派、线宽、配色体系、光照语言（全片唯一，一切帧共用）
- **空间**：同一场景的地形、建筑、光源方位（跨镜头回到同一地点时注入）
- **动作状态**：跨镜头延续的状态量——伤痕、污渍、剑出鞘/入鞘、灯亮/灭、天气与时辰（状态在剧情里改变后，指纹同步更新并记录变更点）核心区分：**文件不重复 ≠ 叙事语义不重复**——帧与帧之间角色语义必须相同（同一个人），而画面必须是叙事上不同的动作瞬间（每帧只声明一个动作增量：低头读信→抬头微笑→大笑）；随机重掷同一画面产不出动画，只产出抖动。变体帧从上一张已过目检的帧链式生成，不从母帧反复重掷，防漂移累积。

**多帧赛璐璐路径（生视频不可用时的动画化兜底）**：生成式视频对多角色复杂帧崩坏时，用生图模型按指纹协议出 A/B/C 三个叙事瞬间帧，各自缓推（zoompan 连续接力，如 1.00→1.02→1.04→1.06）+ 0.2s 微溶接串联——读作手绘动画的动作节拍，身份零漂移、零视频生成成本。

## 路径一：生成式转场与镜头缝合

**准入**：过了 transition-grammar.md 的决策树，确认有"穿越/变形/时空跳跃"叙事含义。

工序：

1. ffmpeg 抽 A 镜头末帧、B 镜头首帧（`-vf "select=eq(n\,LAST)"` 或按时间码 `-ss <t> -frames:v 1`）
2. **风格检查**：两帧色调、光线或画风差异大时，先用已批准且支持参考图编辑的
   provider 做有限度统一，并保留原帧与编辑记录。首尾帧不一致会放大闪变风险。
3. 调用所选 provider 的首尾帧模式（两图 role 分别为 first_frame / last_frame）。
   Seedance 路线按 seedance-video.md 的互斥规则执行；其他 provider 以其适配器能力声明为准。
4. 时长服从 edit plan，通常只覆盖必要的连接动作；分辨率、帧率与成片 profile 对齐
5. 提示词模板：`[起始画面一句话描述]，[过渡语义：镜头穿过/时间流转/场景变形为]，[结束画面一句话描述]。[运镜语义表词汇]。` 不写风格空话。
6. 生成结果两端各留 3–5 帧与原素材做 0.2s dissolve 微融合，掩盖接缝

## 路径二：空镜与静帧

**准入**：shot_manifest 里确实没有可用镜头（先搜一遍再生成）。

分级：

- **静态够用**（垫场、breather、封面）→ 生图 + 已配置的 2.5D 视差处理器，
  或 ffmpeg `zoompan`。先目检深度边缘、遮挡和主体变形，再决定是否采用。
- **需要真实空间变化**（绕主体环绕、穿越、物理交互）→ 生图出首帧 → 已批准的
  `image_to_video` provider

生图路由：

| 场景 | 所需能力 |
|---|---|
| 新建关键帧 / 多分镜组图 | 文生图、指定画幅、可复现参数或批次一致性 |
| 编辑现有帧（补物体/改光线/换动作） | 参考图编辑，并明确声明保构图/保身份能力边界 |
| 角色、场景与道具合成 | 多图输入、角色一致性与目标画幅 |
| 本地优先或敏感素材 | 本地适配器真实支持的能力；不以文生图冒充图像编辑 |

可配置的 Gemini image、OpenAI image 或其他 provider 只是候选执行路线；必须通过
doctor、上传授权和费用闸门后才能调用。生图提示词写明“视频静帧画面”、镜头用途与
安全区；比例与成片一致。

## 路径三：镜头延长

**准入**：镜头拍短了、节奏需要它更长，且轻微变速或插帧不够用或会显假。

- 首选检查可否用轻微变速与已配置的光流/插帧工具；速度、补帧倍率由镜头内容和
  成片 profile 决定，快速遮挡与细线条必须抽帧复核
- 变速不可行（有对白、音乐同步或明显物理变化）→ 使用获准且声明支持视频延长的
  provider；不得把普通图生视频接口当作延长接口

## 路径四：声音补齐

| 缺口 | 执行路线 |
|---|---|---|
| 旁白 / 配音 | 按声音卡选择 Qwen3-TTS、IndexTTS-2、Pocket TTS、LuxTTS 或具备真实适配器的本地引擎 |
| 声音克隆 | 只对获授权参考音执行；记录同意、用途与保留期，优先本地处理 |
| BGM | 使用已获许可素材、本地可调用生成器，或交付按时间线设计的中性提示词包 |
| 画面同步音效 / Foley | 本地录制、获许可素材、确定性合成，或获准的同步音频 provider |
| whoosh / riser / hit / 环境底噪 | 优先本地录制或 ffmpeg/numpy 合成；复杂质感再走获准 provider |
| 生成视频自带音频 | 先分离、审听并记录来源；同步不代表质量合格或自动拥有发布权 |

**定制卡点 BGM**：先定 edit plan 的节奏曲线，再在音乐 brief 中写 BPM、段落长度、
转折与 hit 点。获得成曲后提取 beat anchors，与时间线核对；不中时修改 brief、重剪或
换曲。生成音乐不保证权利清晰，也不保证不会触发 Content ID 或平台相似性检测。

**许可自查**：自托管不改变输入、模型或输出的法律属性。采用任何模型或素材前记录
当前许可证、服务条款、训练/输出限制和目标发行范围；不以开源许可证名称推定输出
一定可商用。

## 插帧通用场景

- 生成片段帧率低或卡顿 → 用已配置的插帧工具转换到成片帧率
- 变速慢动作平滑
- 注意：光流插帧在快速遮挡、交叠和重复纹理上容易产生错位伪影，插帧后必须抽帧目检

## 每个 gap 的即时质检

- [ ] 生成片段与前后镜头色调连续（抽帧并排对比）
- [ ] 无肢体/文字崩坏帧（生成视频常见病，逐段抽帧看）
- [ ] 音画同步偏差 < 40ms
- [ ] actual_cost 已记录，累计未超预算
- [ ] 生成片段路径写回 edit_plan 对应 clip 的 source.path
