## 决策顺序

把剪辑视为观众注意力、信息、情绪和证据的调度，不要视为素材拼接。

先写一句编辑命题：

> 观众在结尾应该理解什么、感到什么、相信什么或做什么？

每次取舍按项目确认的优先级判断。默认顺序为：

1. 事实、同意与证据；
2. 表演和情绪真实；
3. 故事、论点和可理解性；
4. 节奏与注意力；
5. 空间、动作和造型连续性；
6. 技巧与表面精致度。

不要用漂亮镜头掩盖信息缺口，也不要为了动作连续牺牲最真实的表演。若优先级冲突，记录选择和补救方法。

## 纸上剪辑

先让结构成立，再打开渲染器。

1. 建立素材日志：稳定 ID、源时间码、内容、质量、权利、事实用途、表演价值、声音价值。
2. 有采访、对白或旁白时，先做带源时间码的 radio cut。
3. 把序列拆成 beat：目标、阻力、发现、转折、决定、后果、呼吸、结束。
4. 纪录片、科普和产品证明建立 claim-to-evidence map；每个结论指向可核查素材。
5. 画两条曲线：信息密度和情绪强度。两者不必同步，反差常能产生张力。
6. 标出必须看清、必须听清、必须停留和可以省略的部分。
7. 再写 edit plan、声音地图、色彩脚本和缺口清单。

把“没有镜头”和“还没找到剪法”分开。先尝试省略、声音桥、反应镜头、插入、重排或更换论述，再提出补拍或生成。

## 选择素材

逐条评估，不用单一“好看”分数：

| 维度 | 核心问题 |
|---|---|
| 事实/证据 | 它真实支持了什么？是否会误导因果、时间或比例？ |
| 表演 | 微表情、停顿、呼吸、犹豫和反应是否可信？ |
| 叙事 | 它在推进、揭示、对比、转折、兑现还是留白？ |
| 信息 | 观众需要多久才能读懂动作、文字、关系或结果？ |
| 画面 | 构图、视线、动势、景别、焦点和光线是否服务目的？ |
| 声音 | 同期声、语气、空间感或动作声是否不可替代？ |
| 连续性 | 能否自然接入前后镜头？需要什么桥接？ |
| 权利/安全 | 是否已获许可？是否暴露隐私、未成年人或敏感信息？ |

给拒绝素材保留拒绝原因。后续版本若改了叙事目标，可以重新评估，而不是凭记忆找素材。

## 决定剪辑点

先找观众注意力发生转移的位置，再找技术切点。

- 在思想完成、情绪改变、目光转移、动作蓄势或声音提示时切。
- 用 cut on action 隐藏机位变化；不要切掉动作的动机或结果。
- 用反应镜头呈现影响，而不仅是遮盖跳切。
- 对话场景优先保护听者；反应常比说话者更能讲故事。
- 用 J-cut 让下一场先被听见，用 L-cut 让上一场的情绪拖入下一场。
- 给笑声、震惊、结果、证据、字幕和复杂动作足够读取时间。
- 有意识地决定是否保留不完美停顿。纪录片的犹豫、剧情片的呼吸和喜剧的停顿可能比流畅更重要。
- 把跳切当作语法：只有当压缩、焦虑、主观性或网络口语感需要它时使用。

## 维护连续性

把连续性当作理解工具，不当作机械规则。

- **空间：** 轴线、视线、屏幕方向、人物与物体的相对位置。
- **动作：** 起势、接触、重心、速度、手势、道具所在手和完成状态。
- **时间：** 光线、服装、损耗、液位、数量、伤痕、情绪和环境变化。
- **镜头：** 景别、机位高度、镜头感、焦点、运动方向和曝光。
- **声音：** room tone、环境底、混响、距离、透视和噪声。

跨轴前先用中性机位、移动镜头或明确地理镜头重新建立空间。相近机位连切若产生意外跳动，换景别、角度或插入。若故意破坏连续性，用声音、重复、构图或表演建立新的可读规则。

使用 `assets/continuity-sheet.template.md` 跟踪人物、道具、空间、光线和声音。

## 塑造节奏

把 ASL 当测量结果，不当目标。

- 由理解时间、表演呼吸、画内运动、音乐短句和情绪压力共同决定镜头长度。
- 用短镜头提高事件密度；用长镜头增加观察、尴尬、悬念、庄重或真实感。
- 在高密度之后安排呼吸，让观众消化信息并抬高下一次冲击。
- 让音乐结构支持剪辑，不要让每个切点奴役于节拍。
- 卡点时同时使用切镜、画内动作、字幕、声音和刻意漏拍，避免机械等距。
- 高潮不必最长；让建置与蓄势足够，兑现保持准确。
- 喜剧按信息、反应、停顿、再反应控制时序；过早切走会杀死笑点。
- 恐惧和悬念控制“何时给信息”，动作片控制“观众能否理解地理和因果”。

在 beat sheet 中记录节奏意图：加速、减速、波浪、长凝视、突然抽空或主观破碎。

## 使用转场

把转场当标点和语义桥。

| 方法 | 适合表达 |
|---|---|
| 硬切 | 默认推进、对比、冲击、动作或思想连接 |
| 声音桥 | 时间/空间先行、记忆延续、情绪连续 |
| 匹配剪辑 | 动作、形状、构图、声音或概念的隐喻连接 |
| 叠化 | 时间累积、记忆、并置或空间迁移；不要作为通用润滑剂 |
| 淡黑/淡白 | 章节、结束、主观闪回或强烈断句 |
| 遮挡/甩镜 | 素材内已有动势与遮挡时的空间或能量延续 |
| 生成式转场 | 叙事明确需要变形、穿越或不可能的连续运动时 |

每个非硬切转场都写 reason。若只能写“更酷”“更顺”，改用硬切或重新选材。不要让转场覆盖高潮的关键帧、表演或证据。

## 分轮剪辑

不要在一轮里同时修结构、字幕、调色和音效。

1. **同步/组接：** 校验素材、同步、覆盖和缺口。
2. **结构：** 调整顺序、删重复、明确因果、问题和兑现。
3. **表演/证据：** 保护真实瞬间、论据、动作完整性和反应。
4. **节奏：** 调整进入、退出、停顿、呼吸、加速和静默。
5. **连续性：** 修空间、动作、道具、光线、声音和图形。
6. **精剪：** 逐帧修切点、转场柄、字幕、速度和画面重构。
7. **声音/色彩/母版：** 完成混音、色彩管理、可访问性和交付。

每轮保存可回退版本，并写一句 revision note。

## 序列验收

- 能用一句话说出序列的目标和变化吗？
- 每个镜头是否至少承担叙事、证据、表演、地理、节奏或声音中的一项？
- 观众是否知道在哪里、何时、谁在行动、为什么以及结果是什么？
- 是否在正确时刻给了信息，而不是给得越多越好？
- 关键表演、动作、证据和字幕是否有真实读取时间？
- 连续性错误是否打断理解？若故意不连续，规则是否可读？
- 每个转场和速度变化是否有目的？
- 去掉音乐后结构是否仍成立？只听声音时空间和情绪是否仍连续？
- 结尾是在兑现、转义、余韵或行动，而不是素材刚好用完？
