# 钩子与节奏

## 钩子：前三秒定生死

钩子的本质是**在观众脑中放一个未回答的问题**。选钩子镜头的标准不是"最好看"，是"最勾问题"——这是选材最常犯的错。

类型学（edit_plan 与 style_card 的 hook type 枚举）：

| 类型 | 手法 | 适用 |
|---|---|---|
| in_medias_res | 从最强烈动作中间切入，不解释 | 动作/剧情类 |
| suspense | 反常画面或没头没尾的一句话（"我们发现的时候已经晚了"） | 悬念/故事类 |
| result_first | 先给结局一瞥再倒回开头 | 教程/改造/探店 |
| contrast | 预期违背：宁静画面配不祥声音 | 情绪类 |
| audio_first | 画面未到声音先入（J-cut 开场） | 通用，成本最低 |
| question | 直接抛问题字幕/口播 | 干货/知识类 |
| price_anchor | 前 3 秒出价格锚 | 带货 |
| pain_point | 前 3 秒出"人群+痛点" | 带货/解决方案类 |

硬规则：**3 秒内必须有未解问题；8 秒内必须有首次小兑现。**

## ASL：镜头时长是情绪的呼吸

平均镜头时长（Average Shot Length）即情绪温度：

| 情绪 | ASL |
|---|---|
| 沉思/抒情 | 4–8s |
| 常规叙事 | 2–3s |
| 紧张升级 | 1–2s |
| 动作高潮 | 0.5–1s |

节奏设计 = 画一条 ASL 曲线。**向高潮加速剪切**是最基本的张力手段：每个镜头比上一个略短，观众心率跟着走。beat_sheet.md 里必须写明 ASL 曲线走向（accelerating / wave / flat），排片时按曲线给每个镜头分配时长。

## 卡点：会漏拍才是高手

- 重音切画面，弱拍留给**画面内动作**（不切，让画面里的动作踩拍）
- drop 那一拍必须落全片最强镜头
- 连续卡三四拍后**故意漏一拍**，比全程卡点更有呼吸。全程卡点 = 业余
- 工序：先用 librosa 检测 BGM 的 beat_anchors 与能量曲线，标出 drop / breakdown 位置，**倒着从 drop 往前排镜头**——选曲先于剪辑

## 剪辑点的隐身术

- **cut on action**：在动作中途切（抬手到一半切下一机位），动作连续性掩盖剪辑点。观众看不见剪辑，才叫剪辑。
- **J-cut / L-cut**：下一场声音提前 0.5–1s 进（J），或上一场声音拖进下一场（L）。对白戏几乎每个剪辑点都该是 J 或 L；声画同点直切是生硬感的头号来源。edit_plan 的 `j_l_offset` 字段就是干这个的。

## 留白

高密度段落之后必须给呼吸：一个长镜头、一段纯环境音、一次静默。narrative_role 里的 `breather` 不是可选项——30 秒以上的片子至少一处，60 秒以上至少两处。观众需要消化时间，留白也是把高潮衬高的地基。
