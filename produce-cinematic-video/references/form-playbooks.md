## 剧情短片与电影

### 先剪场景意图

为每场写：

- 谁想要什么；
- 谁或什么阻止他；
- 场景从什么状态变成什么状态；
- 最晚何时进入、最早何时离开；
- 哪个 beat 是不可逆变化。

从变化前一刻进入，在后果被观众接住后离开。删掉只重复已知信息的台词和覆盖；保留改变关系、压力或理解的部分。

### 先保护表演

- 选择完整的情绪弧，而不是逐句选择最“标准”的表演。
- 优先听者、反应、眼神和身体；对白只是表演的一部分。
- 使用 room tone、呼吸、衣物和动作声维持身体真实。
- 必须在表演与几何连续性之间取舍时，先保表演，再用插入、反应、声音桥或其他覆盖修复。
- 不要用过多 B-roll 躲避人物脸上的复杂时刻。

### 建立空间与动作

先让观众掌握地理，再压缩动作。动作高潮仍需清楚呈现目标、障碍、接触和后果。用景别、轴线、视线和声音维持方向；主观混乱也要先建立可被打破的客观基线。

### 长片与多场结构

维护 scene card：场次、角色目标、冲突、揭示、情绪温度、时长、前后依赖。每轮结构调整后检查设置/兑现、人物信息首次出现、重复解释和跨场情绪跳变。

## 纪录片与纪实内容

### 建立证据链

在剪辑前区分：

- 同期观察与原始录音；
- 采访陈述；
- 档案素材及其来源；
- 创作者推断；
- 专家解释；
- 图解或模拟；
- 重演；
- 生成图像、声音或视频。

用 claim-to-evidence map 记录每个事实性结论的来源、时间码、限制和反证。不要让蒙太奇制造素材本身不支持的因果、时间顺序、地点关系或人物反应。

### 剪采访

- 保留逐字稿和源时间码，修改文字稿时不丢原上下文。
- 可以删口头赘词，但不要改变语气、确定性、条件或指代。
- 跨句拼接若改变呼吸或含义，改用画面覆盖不能解决伦理问题。
- 对重要争议保留限定语、反方证据和可核查来源。
- 用环境、过程、手部、沉默和观察镜头扩展人物，而不是只做“说话头 + 说明图”。

### 使用重演、模拟和生成内容

- 仅在项目伦理与发行政策允许时使用。
- 在画面、字幕、旁白、片尾或元数据中采用受众可理解的披露。
- 不仿造关键证据、真实人物的未说台词、未发生事件或虚假的同期声。
- 保留生成任务、参考来源、提示、模型、版本和审批记录。
- 对敏感人物、未成年人、创伤和隐私提高审查等级。

### 维护时间真实

区分事实时间、叙事时间和屏幕时间。压缩过程时明确不制造错误顺序；日期、地点、统计和引用在画面锁定前做事实核查。

## 动画

### 先锁 animatic

按 storyboard → scratch dialogue → animatic → layout/blocking → animation → lighting/render → comp → final sound 前进。没有通过 animatic 的节奏、镜头和对白，不要用昂贵渲染掩盖。

在 animatic 检查：

- staging 和 silhouette 是否一眼可读；
- 视线、动作方向和场景地理是否清楚；
- pose、anticipation、action、overshoot、settle 是否完整；
- hold 是否有意，是否为阅读和情绪服务；
- 镜头运动是否来自故事，而非“增加电影感”；
- scratch track 是否支撑口型、呼吸、动作和反应。

### 剪动画表演

- 按 pose 和意图切，不只按对白波形切。
- 让 anticipatory pose 建立预期，让 settle/反应完成结果。
- 保留清晰 silhouette；复杂背景或特效不得抢走动作信息。
- 变速或删除帧时检查 arcs、spacing、接触、重量和布料/毛发的次级运动。
- 口型同步以可理解性和表演为先；避免逐音素机械对齐破坏自然节奏。

### 管理版本

把镜头状态写为 storyboard、animatic、layout、blocking、spline、lighting、final、approved。下游只能使用已批准或明确标记为临时的版本。

## 科学教育与物理过程

把每个镜头当作可验收的实验。

1. 写出学习者应观察、预测或测量的内容。
2. 固定物体数量、尺度参照、初始状态、力源、接触、支撑、连续路径、损耗和最终状态。
3. 先验证一个对象走完完整路径，再扩展到群体、重复或随机过程。
4. 给首帧证明“装置能运行”，给尾帧证明“结果可验收”。
5. 让测量、失败、学生动作和实验结果停留足够时间；不要用音乐或蒙太奇掩盖。
6. 数量、碰撞、参数变化、轨迹或可重复性是核心时，优先 Canvas、Three.js、物理引擎或其他确定性动画。
7. 生成视频适合氛围、角色、过渡和不可测的想象段；不得替代科学证据。
8. 为模拟、生成内容和实拍分别标注来源，保留一版无音乐的干净实验剪辑。

使用 `assets/physical-shot-card.template.md` 和 `assets/acceptance-log.template.csv`。

## 预告片品牌片与社媒短片

### 建立承诺

先写四项：

- **Audience：** 谁会在什么情境看到；
- **Promise：** 观看能得到什么；
- **Proof：** 哪些画面、声音、数据或人物让承诺可信；
- **Action：** 看完后应做什么。

预告片销售的是体验与问题，不是剧情摘要。品牌片把品牌价值变成可见行为，不要只堆形容词。产品片先展示使用情境和证据，再写利益点。

### 设计开场

开场速度由观看情境和内容决定：

- 滑动信息流需要首帧可读、快速建立对象与未解问题；
- 搜索/教程需要迅速确认“这正是我要解决的问题”；
- 社区长视频可以用范围、人物或过程承诺换取耐心；
- 影院、展映和品牌发布允许慢建置，但每秒仍需有意图。

不要把“3 秒钩子”当跨平台定律。记录首个问题、首次兑现和主要 payoff 的实际时间，并用目标受众测试。

### 塑造节奏和包装

- 用结构变化而非持续加速维持注意力。
- 把最强镜头放在承诺、升级或兑现位置，不必总放第一帧。
- 为标题、封面、字幕、安全区、静音观看和 CTA 单独设计。
- 每个平台版本从同一主张与证据出发，允许重排和重包装，不做机械裁切。
- 片尾 CTA 只要求与承诺一致；情绪片可以用余韵，广告片可以用明确行动。

### 保护营销诚信

- 事实性、性能、疗效、价格、稀缺、对比和用户见证都要有证据与适用条件。
- 合成演示、重建效果、加速过程或非典型结果要披露。
- 不预测伪精确播放、获赞、销售或“爆款概率”。

## 选择结构骨架

把结构当诊断和草图，不当时长公式。先选能承载命题的骨架，再由素材、表演、证据和受众测试决定比例。

| 骨架 | 基本运动 | 适用与提醒 |
|---|---|---|
| 三幕 | 建立 → 对抗/探索 → 解决/改变 | 剧情和较长叙事；两个转折必须改变行动，而非只换地点 |
| 起承转合 | 建立 → 展开 → 视角转义 → 收拢 | 散文、动画、品牌和无冲突叙事；“转”可以是理解变化 |
| 预告递进 | 问题/承诺 → 世界与人物 → 压力升级 → 体验兑现 → 片名/行动 | 预告和宣传；不把剧情摘要当建置，不泄露超出策略的结局 |
| 问题—证据—反证—综合 | 提问 → 多源证据 → 限制/反方 → 暂时结论 | 纪录、调查和科普；保留不确定性，避免假平衡 |
| 过程—失败—修正—结果 | 目标 → 尝试 → 可见失败 → 单变量修正 → 验收 | 教育、制作、实验和产品过程；失败证据不能只用旁白代替 |
| 清单/章节 | 总承诺 → 独立条目 → 汇总/下一步 | 教程和中长内容；条目按学习或决策逻辑排序，不盲从“最强放最后” |
| 循环 | 结尾的动作/声音/构图回到开头 | 极短内容或主题表达；循环必须有意义，不能隐瞒已结束 |
| 问题—演示—证明—行动 | 人群/情境 → 真实使用 → 证据/限定 → CTA | 产品和广告；演示与证明必须可核查 |
| 联想/诗性 | 意象、声音或观念之间逐步产生关系 | 电影散文、音乐影像和艺术短片；仍要建立可感知的演变 |

为每段写 function、进入条件、退出条件、信息、情绪和证据。若素材拒绝模板，修改模板；不要为了比例牺牲真实。

## 混合形态

同一项目可同时包含剧情、纪实、动画、实验和营销目标。逐段标记 form 和 truth status，并为整片指定一个最高约束：

- 纪录真实优先；
- 学习证据优先；
- 人物表演优先；
- 品牌承诺优先；
- 形式实验优先。

若两种形态规则冲突，选择更能保护观众不被误导的一条，并在 manifest 中记录。
