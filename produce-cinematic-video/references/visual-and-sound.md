# 视觉与声音

## 构图三条

1. 三分法是底线不是追求；视线方向留空间（look room），运动方向留空间（lead room）
2. 刻意的中心对称构图产生仪式感与不安（韦斯·安德森、库布里克）——打破规则要看得出是故意的
3. 选材时同景别不连切（中景接中景显呆），景别跳一档以上或换轴线角度

## 色彩：一部片一个受限调色板

- 排蓝图时先做**色彩脚本**（color script，皮克斯工序）：每个叙事段一个主色块，写进 beat_sheet
- 色彩随情绪曲线走：开场冷灰 → 中段升温 → 高潮饱和 → 结尾回落
- 冷=疏离/理性，暖=亲密/危险——这是观众的生理反应，不是行业惯例
- 橙青对比（teal & orange）是商业默认味，能用但知道它泛滥；动画/风格化内容大胆偏离
- 主色不超过三个；素材色温不齐时在 QC 标记，交调色处理或选材时规避

## 声音：一半的电影

**静默是最强的音效。** 高潮切点前 0.5–1s 抽掉全部声音（音乐、环境、一切），再砸下去——效果超过任何转场。edit_plan 的 `silence_moments` 字段专为此设。

音效的职能是给剪辑点盖章，不是加热闹：

- riser（上升音）铺在 escalation 段
- whoosh 贴 whip/快速转场
- hit / sub drop 落在高潮切点
- 环境音（ambience）铺满全片底层——完全无声的"空"是穿帮，刻意 silence 才是设计

音乐结构 = 剪辑结构：verse 配建置，pre-chorus 配升级，drop 配高潮。用现成曲库时**选曲先于剪辑，倒着从 drop 排**；用自生成 BGM（ACE-Step）时反转——节奏曲线先定，按 drop 落点定制生成（见 gen-fill-playbook.md 路径四）。

## 混音与响度硬标准

| 项 | 值 |
|---|---|
| 对白下 BGM ducking | -6 到 -12 dB（edit_plan 默认 -9） |
| 网络平台响度 | -14 LUFS |
| 广电交付响度 | -23 LUFS |
| True peak | ≤ -1 dBTP |
| 对白电平参考 | -12 到 -6 dBFS 峰值 |

ffmpeg 实现：`loudnorm=I=-14:TP=-1:LRA=11`（两遍式更准：先 `print_format=json` 测量再带 measured 参数归一）。

## 字幕与文字

- 字幕安全区：底部留 10% 边距，9:16 竖屏避开平台 UI 遮挡区（右侧点赞栏、底部文案区）
- 单行 ≤ 18 个中文字符，停留时长 ≥ 字数 × 0.15s
- 片名卡停留 ≥ 1.5s；tagline 不与片名同屏出现（先后错开更有力）
- word_by_word（逐词弹跳）字幕只用于口播驱动的短视频，叙事片用它即出戏
