# 青少年安全与创作边界

1. 默认 `ZIMA_LIGHT_YOUTH_MODE=true`：提示词与素材检查拦截暴力、色情、霸凌、自伤、仇恨与真实个人信息。
2. 真人照片（尤其未成年人）默认只许本地私有参考，禁止未授权远程上传；上传必须家长/老师明确批准并写入项目 `approvals.json`。
3. 声线克隆仅允许虚构角色或已取得书面同意的样本；默认关闭。
4. 付费 API 调用前必须 `--approve-cost` 或工作室确认对话框；预算写入 `project.json.budget`。
5. 不打包本地 GPU Broker / Comfy / H3 温控；需要专业片场时引导安装完整 `zima-anima`。
6. 成片默认标注「AI 辅助创作」；学校作业场景由用户决定是否公开。
